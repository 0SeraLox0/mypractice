# 🎵 MusikZone — Каталог музыкальных альбомов

> **Тема:** «Каталог музыкальных альбомов» — альбомы, исполнители, жанры.  
> **Ключевые модули:** Рейтинг и рецензии + Подборки «Лучшее за год».  
> **Верстка:** Семантическая верстка (HTML5), CSS Grid & Flexbox, чистая адаптивность на 3 брейкпоинта.  
> **Валидность:** 100% соответствие стандартам W3C, кроссбраузерность.  
> **Экраны проекта:** Главная, Каталог/Список, Детальная страница альбома, Форма добавления рецензии, Подборки «Лучшее за год».

---

## 🏛️ 1. Семантическая структура (W3C HTML5)

Интерфейс размечен с использованием строгих семантических тегов:

*   `<header class="site-header">` — главная шапка сайта с логотипом, десктопной навигацией `<nav class="main-nav">`, быстрым поиском и CTA-кнопкой написания рецензии.
*   `<main class="main-wrapper" id="mainContent">` — основной контейнер контента страницы.
*   `<section class="screen-view">` — каждый экран оформлен в виде логической секции с уникальным заголовком (`<h1>` / `<h2>`) и атрибутом доступности `aria-labelledby`.
*   `<article class="album-card">`, `<article class="review-card">` — карточки альбомов и рецензий размечены как независимые семантические статьи.
*   `<aside class="mini-player-bar">` — дополнительный интерфейсный модуль аудиоплеера с ARIA-меткой `aria-label="Музыкальный аудиоплеер"`.
*   `<nav class="mobile-bottom-nav">` — навигационная панель для смартфонов (Mobile Bottom Tab Bar).
*   `<footer class="site-footer">` — подвал сайта с картой разделов, копирайтом и ссылками.

## 📐 2. Технологии Flexbox & CSS Grid

*   **CSS Grid:**
    *   Сетка альбомов каталога: `display: grid; grid-template-columns: repeat(4, 1fr); gap: 24px;`
    *   Сетка рецензий сообщества: `display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px;`
    *   Пьедестал топа года: `display: grid; grid-template-columns: 1fr 1.2fr 1fr;`
    *   Детальная страница альбома (обложка + метаданные): `display: grid; grid-template-columns: 320px 1fr;`
    *   Сетка характеристик релиза: `display: grid; grid-template-columns: repeat(4, 1fr);`
    *   Подвал сайта: `display: grid; grid-template-columns: 2fr 1fr 1fr 1fr;`
*   **Flexbox:**
    *   Шапка сайта и навигационные ссылки (`justify-content: space-between; align-items: center;`).
    *   Панель фильтров каталога, поисковая строка и переключатели отображения.
    *   Аудиоплеер (обложка + трек + шкала прогресса + кнопки управления).
    *   Блоки метаданных карточек, плашки жанров, теги плюсов/минусов и интерактивный рейтинг со звёздами.

## 📱 3. Адаптивность: 3 брейкпоинта

Интерфейс плавно подстраивается под размеры экрана без искусственных переключателей:

| Брейкпоинт | Диапазон ширины | Особенности отображения |
|---|---|---|
| **1. Десктоп (Desktop)** | `1200px+` | Полноразмерный интерфейс (контейнер до 1240px), 4 колонки альбомов, 3 колонки рецензий, двухколоночный Hero со spotlight-карточкой, десктопное меню в шапке, аудиоплеер закреплен на `bottom: 0`. |
| **2. Планшет (Tablet)** | `768px – 1199px` | `@media (min-width: 768px) and (max-width: 1199px)`. Сетка альбомов перестраивается в 3 колонки, рецензии в 2 колонки, компактный Hero, двухколоночная сетка подвала. |
| **3. Мобильный (Mobile)** | `360px – 767px` | `@media (max-width: 767px)`. Сетка альбомов в 2 колонки (или 1 на самых узких экранах), десктопное меню скрыто, активируется нижний таб-бар (`.mobile-bottom-nav`), аудиоплеер поднимается на `bottom: 60px`, карточки и форма занимают всю ширину. |

## 🖥️ 4. Экраны веб-сервиса

1.  **Главная страница (Home):**
    *   Hero-баннер с альбомом месяца («Random Access Memories»), статистикой (14 800+ альбомов, 86 400+ рецензий) и кнопками быстрого перехода.
    *   Карусель популярных музыкальных жанров.
    *   Сетка популярных альбомов с высокими оценками.
    *   Свежие рецензии от критиков и слушателей.
2.  **Каталог / Список альбомов (Catalog):**
    *   Живой поиск по названию, исполнителю или стилю.
    *   Фильтры по жанрам (Электроника, Рок, Хип-хоп, Джаз, Эмбиент, Инди).
    *   Фильтр по минимальному рейтингу (8.0+, 9.0+, 9.5+).
    *   Сортировка: по рейтингу, по новизне, по числу отзывов.
    *   Переключатель вида: **«Сетка»** ↔ **«Список»**.
3.  **Детальная страница альбома (Album Details):**
    *   Обложка с анимированным виниловым диском.
    *   Блок рейтинга: общий балл (например, `9.6 / 10`), оценка критиков (`97/100`), оценка слушателей.
    *   Интерактивный треклист: **клик по любой композиции включает её в плеере**.
    *   Лента подробных рецензий с плюсами, минусами и лайками.
4.  **Форма добавления рецензии (Review Form):**
    *   Выбор альбома из каталога.
    *   Интерактивный выбор оценки 1–10 с моментальным текстовым вердиктом.
    *   Добавление тегов «Достоинства» и «Недостатки» по клавише `Enter`.
    *   Текст отзыва, чекбокс рекомендации, валидация и моментальная публикация.
5.  **Подборки «Лучшее за год» (Best of the Year):**
    *   Табы переключения годов: 2026, 2024, All-Time Classics.
    *   Пьедестал почёта: 1-е место (Золото), 2-е место (Серебро), 3-е место (Бронза).
    *   Номинации: «Альбом года», «Выбор критиков», «Лучший продакшн».
